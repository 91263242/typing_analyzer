# Typing Analyzer

Monkeytype dizayniga o'xshash professional tez yozish test veb-sayti. Next.js va TypeScript asosida qurilgan.

## Funksiyalar

- ⏱️ **Time Mode**: 15s, 30s, 60s, 120s vaqt rejimlari
- 📝 **Words Mode**: 10, 25, 50, 100 so'z rejimlari
- ⚡ Real-time tezlik o'lchash (WPM - Words Per Minute)
- 🎯 Aniqlik foizini hisoblash (Accuracy)
- 📊 Raw WPM ko'rsatkich
- 📈 Consistency (barqarorlik) o'lchash
- ❌ Xatolarni real-time kuzatish
- 🎨 Monkeytype dizayniga o'xshash dark theme
- ⌨️ Keyboard shortcuts (Tab - restart, Esc - cancel)
- 📱 Responsive dizayn (mobil qurilmalarda ishlaydi)

## O'rnatish

```bash
npm install
```

## Ishga tushirish

Development rejimida:

```bash
npm run dev
```

Brauzerda [http://localhost:3000](http://localhost:3000) manzilini oching.

## Build qilish

Production uchun:

```bash
npm run build
npm start
```

## Texnologiyalar

- Next.js 14
- React 18
- TypeScript
- CSS Modules
